# BEACON

**Bus and External-link Awareness, Continuity, Observation, and Notification for FTC**

BEACON is a phased communications-health and safe-state framework for FIRST
Tech Challenge robots.

This repository is maintained by [The Allsparks](https://github.com/The-Allsparks)
(FTC Team **#36117**). The initial scaffold, research, and Phase 0 library
land in a follow-up pull request.
